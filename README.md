## Notes

Thanks to [Dave Cole and the Pioneers team](https://sourceforge.net/projects/pio/) for creating this game, a faithful, full-featured Settlers of Catan clone with a real AI opponent, seafarers/gold variants, and dozens of official and community map layouts.

## Requirements

Ready to run as-is, no separate download needed. Launching starts a local game against 3 AI opponents automatically - the console server and AI bots are bundled and run in the background, no Wi-Fi or second device required.

This port auto-detects the device's screen shape at first launch and picks Pioneers' own 16:9 (chat panel beside the board) or 4:3 (chat panel stacked below) layout accordingly, so the same build fits both wide and narrow screens.

## Controls

| Key | Action |
|--|--|
| D-Pad / Left Stick | Move cursor |
| A | Left click |
| B | Right click |
| X (hold) | Precision cursor (half speed) |
| Start | Enter |
| Select/Back | Escape |
